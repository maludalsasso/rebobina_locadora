# 📼 Rebobina Vegas — Locadora, Cineclube & Caça-Filmes

> Plataforma web retrô inspirada nas clássicas videolocadoras dos anos 80 e 90 com estética neon de Las Vegas. O projeto une nostalgia e interatividade para resolver a indecisão na escolha de filmes através de um caça-filmes dinâmico, além de contar com um portal de reserva para sala de cinema privativa (15 lugares) e bomboniere com emissão de cupom fiscal vintage.

### 🚀 Funcionalidades Principais
* **Caça-Filme 3000:** Sorteador interativo em JavaScript com animação de rolos desfasados e preenchimento automático de locação.
* **Prateleira de Clássicos:** Catálogo de fitas VHS com filtros dinâmicos por gênero.
* **Cineclube & Sala VIP:** Reserva de sessões exclusivas (individuais, duplas, família e sala fechada).
* **Bomboniere Retrô:** Carrinho interativo com cálculo dinâmico de combos e emissão de comanda/cupom térmico imprimível.
* **TV Tubo CRT:** Player retrô para trailers clássicos com canal rotativo.

### 🛠️ Tecnologias
* **HTML5** semântico
* **CSS3** (Flexbox, CSS Grid, Variáveis e Animações)
* **JavaScript** nativo (Manipulação de DOM e Eventos)
